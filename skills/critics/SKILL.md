# Adversarial Critics

## Overview

Несколько независимых read-only критиков, каждый с ОДНОЙ осью атаки, параллельно рвут артефакт до того, как он стал кодом. Один ревьюер со всеми осями размывается; специализированный ловит то, что генералист пропускает. Сходимость находок разных критиков — главный сигнал истины.

Baseline-провал (20.08.2026, MOB-63351): план v4, написанный без критиков, содержал 8+ high-дефектов (порядок такта, залипающие флаги, проглоченные события); 4 критика сняли их до строчки кода, три независимо сошлись на одном корневом дефекте и одном контуре исправления.

## Оси (дефолтный набор)

| Ось | Что ловит |
|---|---|
| Минимальность/простота | YAGNI, лишние сущности, более короткий путь к цели, переизобретение существующего |
| Корректность | Гонки, порядок событий, состояния-ловушки, сценарии отказа по шагам |
| Архитектура | Слои, владение, контракты, направление эволюции API, аргументы прошлых ADR |
| Надёжность | Лайфсайклы, залипающие флаги, память, регрессии чужих потребителей, отлаживаемость |

Ось под задачу добавлять по смыслу (безопасность, производительность). Меньше 3 критиков — теряется сходимость.

## Промпт критика (обязательные части)

1. Роль: «адверсариальный критик, ось X» — одна ось на агента.
2. Входы: артефакт, референсы (диффы, ADR, прошлые решения), репозиторий read-only. Критик без доступа к коду галлюцинирует.
3. Конкретные вопросы по оси + «не ограничивайся ими».
4. Формат находки: `[severity] + сценарий отказа (шаги → неверное состояние) + доказательство file:line + фикс одной строкой`.
5. «Только находки, без похвал»; «спекуляции помечай „не проверено"».
6. Попросить сквозной вывод — он часто ценнее суммы пунктов.

Запуск: все критики параллельно, subagent type — read-only (Explore).

## Синтез

- Находка, на которой сошлись 2+ критика, — high-confidence; чинить в первую очередь класс, а не симптомы.
- Пользователю — **цитатами, не пересказом** (пересказ искажает; см. правило достоверности в CLAUDE.md).
- Не чинить артефакт, пока не прочитаны ВСЕ отчёты: корневой дефект виден только на пересечении.
- Вердикт честный: если артефакт не выживает — так и сказать, пересобрать, а не латать.

## Common Mistakes

- Один агент со всеми осями сразу — размывается, ловит меньше каждого специалиста.
- Критики с write-доступом — могут «починить» вместо «найти».
- Пересказ отчётов своими словами — искажение; цитировать.
- Прогон критиков ПОСЛЕ реализации — цена находок вырастает на порядок.
- Чинить по первому отчёту, не дождавшись остальных.
