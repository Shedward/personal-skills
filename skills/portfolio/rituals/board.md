# Открыть доску портфеля

Получи [снимок портфеля](../SKILL.md#снимок-портфеля). В командах ниже папка скилла — каталог `portfolio`, где лежит `collect.py`.

Запусти из рабочей копии `<папка скилла>/../todo/serve-board --portfolio <снимок.json> [--current <ключ>]`. Папка Markdown берётся из `tasks_root` снимка, при необходимости передай `--tasks <папка>`. Сервер подхватывает изменения карточек и замену снимка Jira. При загрузке ключ ветки определяет раскрытый тикет. Если ветка вне портфеля, его можно указать через `--current`.

В Codex Desktop всегда открывай напечатанный URL во встроенном браузере с комментариями в текущий чат. Оставь доску открытой. Рядом открой Inbox во вкладке того же браузера или используй уже открытую. Команда `plannotator inbox --background` возвращает его URL.

Без встроенного браузера или по просьбе о статической копии используй `python3 -IB <папка скилла>/board.py <снимок.json> <scratchpad>/board.html`. Для комментариев открой `plannotator annotate <scratchpad>/board.html`; без Plannotator передай путь к HTML вместе с каталогом вложений `board-assets`, если он создан.

Состояние PR бери из Forgejo по правилам проекта. Передай проверенные результаты через `--prs <файл.json>` в формате `{"APP-12": [{"label": "#34 · открыт → PLAN-4", "url": "https://example.org/pulls/34"}]}`. Пустой массив означает подтверждённое отсутствие PR, пропущенный ключ — сведения не проверены. Для проверки готовности учитывай слияние PR, локальные вопросы и этапы сдачи.

В строке портфеля счётчики всех его карточек, при раскрытии — только собственные. Название тикета открывает кешированное описание. Ссылка «Jira ↗» в заголовке живой доски открывает сам тикет в системном браузере. Карточка открывает полный текст локальной задачи и вложения. Комментарий `[n]` относится к уникальному номеру на этой сборке доски, `#general-comment` — ко всему портфелю. В Plannotator для навигации нужен режим Interact (из Annotate — Esc).
