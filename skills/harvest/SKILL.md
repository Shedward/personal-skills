# Harvest

Конец сессии — единственный момент, когда знания сессии ещё живы. Скилл
прогоняет шесть категорий, собирает инвентарь кандидатов и записывает только
то, что пользователь выбрал.

## Процесс

1. **Скан сессии** по категориям (ниже). Пусто — так и сказать: «harvest
   пустой», не изобретать записи ради записей.
2. **Инвентарь на выбор**: нумерованный список «что → куда», по строке на
   кандидата. Никаких записей до выбора пользователя.
3. **Записать выбранное** по правилам целевого места (форматы — в их
   скиллах/конвенциях, не здесь).

## Категории

| Что искать в сессии | Куда |
|---|---|
| Пользователь исправлял моё поведение голосом («не делай X», «лучше Y») | Доступная память текущего приложения: feedback-запись с Why / How to apply; если записи памяти нет — предложить правило для файла инструкций |
| Новый или улучшенный приём отладки, подводный камень трюка | Скилл debug-tricks (его правила harvest — в нём самом) |
| Дебажили/изучали подсистему, узнали неочевидное об архитектуре | Карта подсистемы (скилл map-subsystem; только закоммиченное, без WIP) |
| Надолго завязли из-за моего систематического поведения | Кандидат-правило для Claude: `~/.claude/CLAUDE.md`; для Codex: `~/.codex/AGENTS.md` — предложить формулировку и согласовать целевые файлы |
| Проектное решение, договорённость, термин | `~/.claude/docs/<project>/` (ADR / CONTEXT.md) |
| Нашли баг/идею/вопрос и не сделали; взяли задачу из беклога и сделали | Скилл todo — завести задачу; закрыть взятую (статус в файле должен совпасть с реальностью) |
| В группе задач текущей ветки не осталось незакрытых | Скилл todo — сказать «группа готова к ревью» и предложить закрыть группу |
| Открытые задачи, которых сессия коснулась (текущая группа и беклог, отобрать релевантные по теме) | Скилл todo — предложить дописать в Notes задачи найденный факт, `file:symbol`, ссылку на заметку или коммит; датированная строка в Logs |
| Создавали или правили личный скилл | Скилл skills-sync — забрать в репо, напомнить про коммит |

## Ошибки

- `~/.claude/docs/` — общее хранилище проектных знаний для обоих приложений.
  Память и глобальные инструкции приложений раздельные: не обещать их
  синхронизацию и не копировать целиком правила из одного приложения в другое.
- Записывать без выбора пользователя — нельзя, сначала инвентарь.
- Дублировать содержимое целевых скиллов здесь — протоколы живут там.
- Тащить в карты и память детали незакрытых задач (WIP) — они ещё изменятся.
